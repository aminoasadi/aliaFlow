# Aliaflow componentized Next.js build

This is a component-first reconstruction of the supplied Aliaflow Figma source.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Component map

- `Header` — responsive navigation menu
- `Hero` — lead statement and strategic-table image
- `OutcomePanel` — reusable different / competitive / scalable panels
- `ServiceCatalogue` — interactive, keyboard-accessible service tabs
- `Pillar` — reusable pillar layout
- `ProjectLoop` — Alialab / Aliapay / Aliasys portfolio cards
- `TrustSection` — positioning and team cards
- `Footer` — contact CTA and supporting links

All page structure, type, layout, controls and decorative surfaces are code. The only raster files are the individually supplied image assets in `public/assets`.
